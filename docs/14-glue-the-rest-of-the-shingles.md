# Glue the Rest of the Shingles

At this point you just need to glue on the 32 other shingles. It should become very routine at this point. Be sure that you dab glue on ALL surfaces where the shingles touch the core or other shingles. Don’t forget the ‘side’ channels where shingles touch each other (see below), however DON’T put any glue in any of the channels meant for the leaves.

<img src="../images/glue-in-the-side-channels-between-shingles.jpg" alt="Glue in the side channels between shingles" width="218">

When you are done it should look like this

<img src="../images/trunk-with-all-the-shingles.jpg" alt="Trunk with all the shingles" width="553">


## Sand the Trunk!

Now that the trunk is assembled, you should sand it. DO IT NOW! If you wait, it is basically impossible to sand and it will look A LOT better if it is sanded.
