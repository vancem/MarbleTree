# Laser Cutting Instructions

The marble tree can be built in basically two ways

- You can cut out the pieces using a table saw and a scroll saw (old school).
- You can cut out all the pieces using a laser cutter.

These instructions are for the laser cutting option.

It takes about 2-3 hours to assemble the toy after all the pieces have been laser cut. Typically it takes about 40-60 min of actual laser cut time to cut all the pieces.

You will need 3.5-4 square feet of 1/8 plywood, sandpaper, wood glue some rubber bands (helps when gluing) and access to a laser cutter. Having a glue brush helps quite a bit and is recommended.
